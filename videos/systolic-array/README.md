# Systolic-array videos

- [Complete animated presentation](presentation.mp4)
- [Matrix multiplication chapter](matrices.mp4)
- [Systolic operand-flow chapter](dataflow.mp4)

Each video has SRT captions, chapter markers, and a reading transcript.
`render-info.json` records exact settings, software versions, dimensions,
durations, and file hashes. The complete presentation uses an FFmpeg H.264
delivery encode (CRF 20) at the original 720p/30 fps; its source hash is retained.

See [the project guide](../../docs/systolic-array.md) for the equations, source
evidence, rendering commands, and animation structure. Original speaker notes
are preserved in [the source-notes document](../../docs/systolic-array-speaker-notes.md).
