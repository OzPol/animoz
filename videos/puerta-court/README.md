# Puerta Court videos

The survey and physics videos explain the geometry and motion model. Separate
`replay-<view>.mp4` and `survey-view-<view>.mp4` clips share identical physical
coordinates. `viewer.html` provides offline camera controls and time scrubbing.

Explanatory clips include SRT captions, chapter timestamps, and a reading
transcript. `render-info.json` records exact inputs and file hashes.
See [the project guide](../../docs/puerta-court.md) for commands, measurements,
the explicit motion hypothesis, and the missing inputs for accident visibility.
